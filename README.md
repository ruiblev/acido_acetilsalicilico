# Simulador de Síntese - Ácido Acetilsalicílico 🧪

Este é um simulador interativo desenvolvido em **Python** com **Streamlit**, focado no procedimento laboratorial da síntese do ácido acetilsalicílico (Aspirina).

## 🚀 Funcionalidades

- **Modo de Estudo**: Guia passo a passo pelas 12 etapas do procedimento, com animações e interações visuais.
- **Modo Prático-Experimental**: Testa o conhecimento do utilizador, exigindo a seleção correta de materiais e ações antes de cada fase.
- **Interatividade Total**: Componentes visuais personalizados para pesagem, pipetagem, aquecimento, filtração e muito mais.
- **Cálculo de Rendimento**: No final, o simulador gera uma massa experimental baseada nas variáveis do processo (como a temperatura de aquecimento) para que o utilizador valide os seus cálculos.

## 🛠️ Tecnologias Utilizadas

- [Python](https://www.python.org/)
- [Streamlit](https://streamlit.io/)
- HTML/CSS/JS (para componentes interativos personalizados)

## 📦 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/ruiblev/acido_acetilsalicilico.git
   cd acido_acetilsalicilico
   ```

2. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```

3. Execute a aplicação:
   ```bash
   streamlit run app.py
   ```
